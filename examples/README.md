# 范例

- `starter/`：户外场景的起点。地面、路、树、草、黄昏的光，能直接跑。先从这里改。
- `jetty/`：用这个 skill 做的一个小题：黄昏走向湖边的木栈桥，6 秒。有岸、有水、有对岸的树林，栈桥和小船是脚本建的。`start.jpg`、`stop.jpg` 是成品的第一帧和最后一帧。改了六轮，过了两次只看画面的评审；评审之后还留着的问题写在 `references/look.md` 的“试做栈桥时学到的”一节。
- `machu-picchu/`：真实地方的完整例子。马丘比丘从梯田走进古城正门，24 秒：地图和高程、照片投到地形上、照着照片描出来的门、方案图、四个建模脚本、云渲染的渲染命令和网页署名。2026-11-22 GPT-6.2 Astra 在 Codex 里用这个 skill 从空文件夹做出来，从头重建只要不到一分钟，画面和成片一致。用法见里面的 README。
- `lakeside/`、`promo/`：作者网站首页那条片子和它的宣传片的原脚本。只在作者本机，不随 skill 分享；本机有时可以去查原做法。
